# Role-Based Access Control (RBAC) - Backend API

A secure and scalable Node.js and Express backend built for managing authentication, user profiles, and dynamic Role-Based Access Control (RBAC) with MongoDB.

---

## 🚀 Features

* **JWT Authentication:** Secure token-based user login and registration with password hashing (`bcryptjs`).
* **Role-Based Authorization:** Custom middleware to protect routes based on user roles (`Admin`, `Manager`, `User`).
* **Admin Management Panel:** Endpoints allowing administrators to fetch all users and dynamically update user roles.
* **Database Integration:** Persistent data storage using MongoDB and Mongoose.

---

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB, Mongoose
* **Security:** JSON Web Tokens (JWT), bcrypt.js, CORS
